# CodeQuest MCP — этап 7: квесты

Спек §3.3 (пакеты), §3.4, §7. Ветка `stage-7`. Пишу и проверяю сам, без субагентов (решение пользователя: экономить
лимиты). Этап большой, поэтому три части, каждая — свои коммиты и `npm run check`.

## Часть A — пакеты «магазин» и «бот» (сканер)

1. Тип проекта (`analyzer/domains.ts`): `facts.domains`. Пакеты `shop` и `bot`, общий `generic` включён всегда.
2. `Rule.pack`: правило пакета запускается, только если пакет включён (уверенность ≥ 0.5).
3. Правила: `shop/webhook-no-signature`, `bot/no-error-handler`, `bot/admin-no-check`, `bot/fat-router`,
   `bot/no-timeout`. Пакет «магазин» поднимает до high непротестированные модули оплаты и заказа.
4. Фикстуры правил и проектов: находки, которые в этапах 2–3 были только «семенами», теперь настоящие.

## Часть B — генерация квестов (`game/quests`)

Шаблоны §7.1, пачки §7.2, сложность §7.3, приоритет §7.5, номер квеста §7.7, «как было» `Baseline` §8.2.

## Часть C — эпики, адаптация, доска

Эпики §7.4, адаптация §7.6, доска §7.7 (до 8 квестов, до 3 из категории, 1 эпик), порядок и карточки, устаревание.

## Договорённости

- Правила читают только `ctx`; ключи находок без номеров строк; регулярки по всему файлу без неограниченных префиксов.
- `game/` — чистые функции; время и уровень приходят параметрами.
- Подробности частей B и C дописываются в этот файл перед их началом.
